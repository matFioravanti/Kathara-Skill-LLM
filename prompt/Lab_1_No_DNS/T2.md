Nel laboratorio Kathara esistente configura un DNS gerarchico interno dual-stack.

Fai:
- Configura `pc2dual` come root server autoritativo per `.`.
- Configura `pc5dual` come autoritativo per `test.`, delegata da `pc2dual` con record NS e glue corretti.
- Configura `pc3dual` come resolver ricorsivo che parte dalla root interna `pc2dual`.
- Configura `pc1dual` come web server e fai risolvere `www.test.` verso `10.1.0.30` e `fd00:1::30` tramite record A e AAAA nella zona `test.`.
- Configura `pc4v6`, client solo IPv6, perché usi `pc3dual` tramite `fd00:3::30`.
- Configura i client IPv4 perché usino `pc3dual` tramite `10.3.0.30` e gli altri client IPv6 tramite `fd00:3::30`.

Non fare:
- Non assegnare più ruoli DNS alla stessa macchina.
- Non usare forwarder, DNS pubblici o root pubbliche.
- Non fare interrogare direttamente ai client `pc2dual` o `pc5dual`.
- Non modificare topologia, routing, gateway o indirizzi del laboratorio.
