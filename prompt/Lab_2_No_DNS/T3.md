Nel lab Kathara esistente, lascia invariati i cinque router, i dieci host, gli indirizzi e il routing statico IPv4/IPv6. Configura `pc2` (`100.0.6.2`) come root DNS autoritativo per `.` via IPv4 e `pc8` (`2001:db8:2::8`) come unico autoritativo per `test.`, con delega NS e glue AAAA dalla root. Su `pc8` crea `www.test. AAAA 2001:db8:4::9`; `pc9` (`2001:db8:4::9`) ospita il web server HTTP IPv6. Configura `pc3` (`100.0.0.2`, `2001:db8:3::2`) come resolver ricorsivo dual-stack basato sulla root hint interna di `pc2`, senza forwarder e con `dnssec-validation no;`. `pc4` deve usare `pc3` via IPv4 e `pc6`, IPv6-only, via IPv6; entrambi devono risolvere il nome, mentre `pc6` deve anche poter raggiungere il web server. Non usare DNS pubblici, non mischiare i ruoli e non aggiungere record A, host statici, host, indirizzi o rotte.
