Ho già un laboratorio Kathara con cinque router, routing statico IPv4/IPv6 e gli host `pc1`–`pc10`. Voglio aggiungere una gerarchia DNS interna senza cambiare la rete. `pc2` (`100.0.6.2`) deve essere la root autoritativa per `.` via IPv4; `pc8` (`2001:db8:2::8`) deve gestire soltanto `test.`, delegata dalla root con NS e glue AAAA corretti. In quella zona crea `www.test. AAAA 2001:db8:4::9`; il web server è `pc9` e risponde su `http://[2001:db8:4::9]/`.

I client devono chiedere i nomi a `pc3` (`100.0.0.2`, `2001:db8:3::2`), che risolve partendo dalla root hint interna su `pc2`. Non configurare forwarder e imposta `dnssec-validation no;`. `pc4` deve usare il resolver via IPv4; `pc6`, che è IPv6-only, via IPv6. Entrambi devono ottenere la risoluzione DNS di `www.test.`; `pc6` deve anche raggiungere il web server IPv6, mentre `pc4` non deve essere modificato per acquisire connettività IPv6.

Non assegnare più ruoli alla stessa macchina, non usare DNS pubblici e non modificare topologia, indirizzi, gateway o routing statico. Non aggiungere host, rotte, record A per `www.test.` o voci statiche in `/etc/hosts`.
